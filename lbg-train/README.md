# Паровоз Mikado в скоростной состав (прототип для сайта LBG)

Интерактивная 3D-страница: паровоз Mikado 2-8-2 с тендером раскладывается и собирается в трёхвагонный скоростной состав.

- Готовая страница: `dist/lbg-mikado-hst.html` (один офлайн-файл, открывается двойным щелчком).
- Скриншоты состояний 0, 25, 50, 75, 100%: `stills/desktop_*pct.png`, вид на телефоне: `stills/phone_*pct.png`.
- Исходники: `mikado-hst/main.js` и `mikado-hst/style.css`.

## Как пересобрать

Нужен навык teardown (`npx skills add elvarofficial/teardown -g -a claude-code -y`, затем `npm install` в его папке).

    node ~/.claude/skills/teardown/sims/build.mjs ./lbg-train/mikado-hst

Результат появится в `teardown-out/dist/mikado-hst.html`.

## Как устроено

- Один вход: прогресс `p` от 0 до 1. Положение каждой детали считается формулой от `p`, ключевых кадров нет.
- У каждой детали есть поза A (в паровозе) и поза B (в составе). Она сначала раскрывается наружу, потом летит по дуге на своё место, поворачиваясь на шарнире или переворачиваясь.
- Оболочки (смоковая коробка, котёл, топка, бак тендера, угольный бункер) меняют форму через morph target: цилиндр становится кузовом или носом. Цвет, окна и бордовая полоса проступают в шейдере по мере сборки.
- Рама из трёх вложенных коробов выдвигается телескопически с 21 до 31 м.
- 12 колёсных пар (6 паровоза и 6 тендера) переезжают в 6 тележек и уменьшаются до одного диаметра. Боковые тяги, шатуны, ползуны и штоки на старте считаются по настоящей кинематике кривошипа, потом становятся тягами тележек.
- Гидроцилиндры на экране соединяют детали с рамой и растягиваются по мере движения.
- Панели читают те же величины, что двигают детали (скорость, длина, число собранных вагонов).

## Путь основных деталей

| Было | Стало |
|---|---|
| Дымовая коробка, верх и низ | Нос головного вагона |
| Котёл | Кузов головного вагона |
| Топка | Кузов среднего вагона |
| Бак тендера | Кузов хвостового вагона |
| Угольный бункер | Хвостовой обтекатель |
| Крыша кабины | Лобовое стекло |
| Стенки кабины, подножки, боковины тендера | Шесть дверей |
| Передняя и задняя стенки кабины | Переходы между вагонами |
| Дымовая труба, паровой колпак, песочница | Крышевые блоки |
| Цилиндры | Подвагонные модули |
| Колёсные пары, рамы тележек | 6 тележек |
| Уголь | Пульт кабины |

## Что осталось недоделанным

- Эталоны только по фото Mikado (Union Pacific) и концепту Siemens Velaro: размеры взяты на глаз, а не с чертежей.
- Проходов деталей друг сквозь друга в середине перестройки полностью не исключено.
- Нет дыма, звука и записи видео (в навыке для видео есть `capture.mjs`, сцену под него ещё не оформляли).
- Паровоз простой: нет клапанного механизма, поручней, труб и мелкой арматуры.
